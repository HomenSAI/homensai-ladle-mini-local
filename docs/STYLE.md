# Четыре скина и ядро HomenS.AI

Ориентир — `HomenSAI/homensai-style`, версия **1.14.3**, прочитанная из `VERSION`. Палитры Nordic и Paper, тонкие линии, спокойный интерфейс, семантические цвета, текстовые обозначения состояний и крупные цели касания взяты за основу мобильной адаптации.

Это не четыре приложения и не четыре независимых набора данных. Свойство `shop.skin` меняет CSS-токены и плотность карточек одного интерфейса.

| Скин | Основные цвета | Поведение |
|---|---|---|
| 01 — light | Nordic: #edf1f4 / #f9fbfc; акцент #1f7a46 | Светлый, зелёные действия, просторные карточки |
| 02 — dark | Nordic: #0f1720 / #16212c; акцент #5fc388 | Тёмные поверхности, светлый текст, зелёные действия |
| 03 — paper | Paper: #f3eee3 / #fbf8f1; акцент #8a3b12 | Тёплый бумажный вариант, коричневые акценты |
| 04 — compact | Nordic light; акцент #1e4f8a | Более компактная списочная подача, синий акцент |

Пользователь одобрил эти четыре направления в разговоре. Зелёный основной акцент первых двух — адаптация для Lädle из семантического зелёного ядра, а не заявление, что `--accent` исходного Nordic является зелёным. В исходном Nordic основной акцент синий. Новая версия самого ядра не создавалась, изменения в его репозиторий не отправлялись.

Из изображений-концептов не переносились лишние графики, фото мяса, декоративные меню и произвольные суммы. В Mini Local добавлены собственные фотографии карточек; графики и отдельная вкладка общей аналитики не добавлялись. Данные и доступные функции у всех скинов одинаковы.

Стек гарнитур начинается с IBM Plex Sans/Mono при наличии в системе, затем используются системные аналоги. **Шрифтовые файлы не включены**, поэтому пиксельное совпадение с ядром/картинками не заявляется. Словесный бренд написан как **HomenS.AI**; для launcher создан простой самостоятельный вектор магазина. Закрытые файлы логотипа и робота из ядра не копировались.

Номинальные размеры элементов ввода/кнопок не меньше 48 CSS px, адаптация протестирована на ширинах 320, 360, 412 и 800 px. Семантические текстовые токены и текст кнопок проверены на контраст 4,5:1; значения в `reports/source-checks.json`. Это проверка выбранных пар цветов, не сертификация всего UI по WCAG. Проверка TalkBack/реального Android fontScale ещё предстоит.

В браузерной автономной HTML-сборке CSS/JS объединены с hash-CSP для удобства просмотра. В Android исходные файлы остаются раздельными, с `script-src 'self'` и без inline-обработчиков.
