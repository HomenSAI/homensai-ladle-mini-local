# Каталог Mini Local

91 шаблон, 16 групп, 16 схематичных SVG-иллюстраций. Свои фотографии можно выбирать и удалять; картинки не являются медицинским/ветеринарным руководством или точной схемой разделки конкретной туши. Фото магазина в пакет не выдуманы.

На новой установке активны только молодая говядина, говядина, баранина, курица, кабан и оленина — 51 карточка. Крольчатина и прочие группы отключены. Jungrind и Kalb — разные категории, а не замена одной другой. Возраст животных и конкретные торговые наименования приложение не определяет: их подтверждает продавец.

Карточка хранит имена DE/EN/RU; немецкое имя обязательно, остальные могут быть заполнены позже и использовать fallback. У всех встроенных карточек заполнены три языка. Категории фиксированы стартовым справочником, произвольные товары добавляются в подходящую категорию либо «Прочее».

DefaultPrice отсутствует до ввода продавца; это не нулевая цена. Unit: kg/piece/pack/litre. Тушка, заказанная в штуках, в Mini не переключается автоматически на оплату по кг: выберите единицу продажи заранее. Сложная схема «резерв одной птицы, окончательная стоимость по весу» — отдельная функция, не реализована.

Удалить неиспользованный шаблон можно полностью. Использованный будет архивирован; восстановление возвращает его неактивным. Цена/имя/единица каталога не переписывают дату и уже принятый заказ. Любую иллюстрацию можно заменить собственной локальной фотографией. Импорт JPEG/PNG/WebP ограничивается, изображение уменьшается, выход JPEG без исходных метаданных. Android-импорт требует проверки на устройстве; browser-версия действительно проверена синтетическим файлом 1600×1200.
