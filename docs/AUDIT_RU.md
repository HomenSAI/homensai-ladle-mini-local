# Аудит Mini Local 0.3.0

Проверка собственного кода и автоматизированных сценариев, не независимая экспертиза. Удалённые сервисы отсутствуют и не тестировались.

## Исправлено в исходниках

- Ассортимент новой установки ограничен указанными фермерскими группами; молодая говядина отделена от телятины; кролик выключен.
- Предзаказ, накопительный факт и накопительная оплата разделены. Дополнительный фактический товар не меняет предзаказ; частичная выдача не закрывает день.
- Количества типизированы; штуки/упаковки не допускают дробей и не прибавляются к килограммам. Сортировка веса клиентов учитывает только кг, количественная сортировка товаров группируется по единице.
- Поиск покупателей по товару включает дополнительные фактические покупки.
- Добавлены авточерновики, локальный журнал, аварийный выбор пяти снимков, DB-миграция без удаления данных.
- Свои изображения ограничиваются, уменьшаются и очищаются от исходных метаданных.
- Мини-версия использует отдельный applicationId и не заменяет предыдущую программу автоматически.

## Открытые вопросы

| Приоритет | Состояние |
|---|---|
| P0: APK / Android Lint / native API | Не выполнены. Свежая попытка сборки остановилась на загрузке Gradle (DNS). |
| P0: Android SQLite, lifecycle, recovery, SAF, photo picker | 25 тестов подготовлены, но ни один не запускался на Android. Нужна ручная приёмка. |
| P1: база не зашифрована отдельно / нет app PIN | Системная блокировка; дополнительная защита — следующий этап. |
| P1: размеры данных | 8 MiB снимок, 10000 audit строк. Нужна долговременная архивация и тест на объёме; photos входят в лимит. |
| P1: процесс и резервные копии | Браузерный рестарт смоделирован; process death Android, перенос/возврат копии — не проверены. |
| P1: собственная фотография | Browser импорт проверен; Android Bitmap/Exif/SAF — только исходники и подготовленные тесты. |
| P2: доступность | 320/360/800 px, 150% текст — браузерные проверки; TalkBack/200%/системный Android scale не проверены. |
| P2: журнал | Ограниченная сводка операций, не полный бухгалтерский/фискальный журнал и не защита от владельца данных. |
| P2: смешанная единица одной позиции | Резерв тушки в штуках с финальной ценой за кг не поддерживается. Одна единица на позицию. |

Это не касса и не платёжная система: нет авансов до выдачи, эквайринга, фискальных чеков и налогового расчёта. Самостоятельные продажи без привязки к клиентскому заказу не включены. Сервер, клиентские подписки, push и Pro намеренно вне этой поставки.

## Решение

Готова исходная локальная функциональная версия для дальнейшей сборки и испытаний. **Не Android-релиз для реальных заказов.** Допуск только после успешной сборки, нативных тестов, ручной приёмки и проверенной внешней резервной копии. Отсутствие сервера не устраняет необходимость проверки сохранности на телефоне.
