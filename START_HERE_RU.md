# Lädle Mini Local 0.3.0 — начать здесь

## Что вы получили

Исходники Android-приложения, браузерную демонстрацию, тесты, изображения интерфейса и инструкции. **APK отсутствует.** В этой среде не удалось скачать Gradle и нет Android SDK/эмулятора. Поэтому архив нельзя просто установить как Android-приложение. Для установки потребуется сначала собрать APK на компьютере.

## Быстро посмотреть интерфейс

Откройте `preview/Laedle-preview.html` в современном браузере. Это автономный файл без сайта и сервера; он предназначен для знакомства с вымышленными данными. В Chromium тестировались интерфейс и расчёты с хранилищем в памяти. Сохранение в конкретном браузере телефона и работа HTML через просмотрщик файлов не проверялись. Предпросмотр не подменяет Android-приложение и его SQLite.

При первом запуске пройдите мастер: название магазина, контактное лицо, адрес и контакты, часы/условия выдачи, язык, скин. Кроме названия, данные магазина необязательны; настоящие сведения за вас не выдуманы. Включайте вымышленные примеры только для испытаний.

## Собрать и установить для теста на телефоне

1. На компьютере установите Android Studio и через SDK Manager — Android SDK Platform 36, Build Tools 35.0.0, Platform Tools. Также нужны JDK 17/21 и Python 3.10+. Условия SDK принимает владелец компьютера.
2. Распакуйте ZIP. В Windows запустите `BUILD_APK_WINDOWS.cmd`, в Linux/macOS — `bash BUILD_APK.sh`. При необходимости задайте JAVA_HOME и ANDROID_HOME. Подробности и альтернативы — `docs/BUILD.md`.
3. Только если сборка завершилась успешно, появится `app/build/outputs/apk/debug/app-debug.apk`. Перенесите его на тестовый телефон и откройте установщиком Android. При запросе разрешите установку именно выбранному источнику, а после установки отключите разрешение.
4. Приложение называется `Lädle Mini Local · Test`. Проект задаёт минимум Android 8.0 и проверяет System WebView 111+. Это требования исходников, не подтверждение испытаний на всех таких устройствах.
5. Пройдите `docs/ACCEPTANCE.md` на вымышленных данных. Начинать учёт настоящих заказов до проверки сохранения, повторного запуска, обновления и резервной копии не следует.

**Mini Local имеет отдельный идентификатор:** `com.homensai.laedle.minilocal.debug` в тестовой сборке, `com.homensai.laedle.minilocal` в release. Старую Lädle она не заменяет. Перенос — через зашифрованный экспорт старой программы и импорт в новую. Перед импортом новой программы сделайте собственную резервную копию: импорт заменяет её данные, не объединяет две базы. Формат старых данных v1/v2 мигрирует без изменения старых заказов; новый профиль активных мясных групп применяется только при свежей настройке.

## Каталог магазина

Включены молодая говядина (Jungrind), говядина (Rind), баранина (Lamm), курица (Hähnchen), дикий кабан (Wildschwein), оленина (Hirsch). Молодая говядина не отождествляется с телятиной. Крольчатина присутствует, но отключена, пока магазин не подтвердит продажу. Прочие группы тоже доступны по фильтру неактивных/всех товаров.

Всего 91 шаблон, из них 51 активный. Каждый можно переименовать на трёх языках, задать цену и единицу, включить/выключить, заменить иллюстрацию собственным фото, архивировать/удалить. Названия отрубов — стартовые заготовки: продавец должен сверить их со своим прайсом. Пустая цена требует заполнения; цена 0 — отдельный осознанный ввод.

Неиспользованный шаблон удаляется полностью. Использованный архивируется, чтобы сохранить историю заказов. После восстановления из архива он остаётся неактивным, пока его не включат.

## Обычный день работы

**Дата → ассортимент → заказы → подготовка → фактическая выдача → оплата → закрытие.**

Добавьте дату и время выдачи, затем товары и цены. Название и цена каталога копируются в дату, а далее в заказ. Переименование/переоценка шаблона не меняет уже принятые заказы.

В «Покупателях» добавьте фамилию, имя, необязательный телефон, позиции и количества. Существующий клиент выбирается из справочника. В «Подготовить» отображаются общий план по каждому товару, покупатели, реальные продажи и оставшееся количество по ещё не завершённым выдачам.

Доступны кг, штуки, упаковки, литры. Кг и литры — до трёх десятичных знаков; штуки и упаковки — целые числа. Они не складываются в один вес. «Вес» в сортировке покупателей учитывает только килограммы, сортировка товаров по количеству сначала группирует по единице.

При выдаче введите фактическое количество и цену. Для частичного получения оставьте «Выдача завершена» выключенным. **При следующей выдаче вводится суммарное количество за все получения, не добавка к прошлому:** сначала выдали 1 кг, затем 0,5 кг — новая запись 1,5 кг. Дополнительные позиции можно выбрать из ассортимента этой даты; исходный предзаказ не изменяется.

«Оплата» фиксируется отдельно. **Введите всего получено по заказу**, не новый платёж: сначала 20 €, затем ещё 10 € — укажите 30 €. Наличные/карта/другое — только отметки способа; приложение не проводит платёж и не является кассой. Сумма выше фактической продажи не принимается. Чтобы уменьшить факт ниже оплаченного, сначала явно исправьте полученную сумму; возврат средств программа сама не выполняет.

Закрыть дату можно, когда все заказы выданы полностью либо отменены. Частичная выдача закрытие блокирует. После закрытия оплаты можно уточнять, а для изменения товаров/факта дату нужно явно открыть снова.

## Сохранность

Основная запись сохраняется только по «Сохранить». Незавершённая форма сохраняется отдельно как черновик: при старте его можно продолжить или отбросить. Черновик старой ревизии не перезаписывает более новые заказы. При повреждении базы предусмотрен аварийный экран с выбором одного из пяти предыдущих валидных снимков; выбранный снимок возвращает магазин к более раннему состоянию и может не содержать последние изменения. Нативный путь восстановления ещё требует проверки.

В разделе магазина создавайте зашифрованную резервную копию под паролем (не короче 10 символов). Пароль не хранится и не восстанавливается. Сохраните копию вне единственного рабочего устройства — например, вручную на компьютер или USB-накопитель — и действительно проверьте восстановление. Это не требует сервера программы.

Не удаляйте рабочее приложение и не очищайте его данные для исправления ошибки без проверенной копии. Для обновлений нужен тот же applicationId и ключ подписи; ключ release хранится отдельно от Git. Локальная SQLite не шифруется дополнительным ключом приложения: используйте блокировку самого телефона. Журнал изменений не является неизменяемым фискальным журналом.
